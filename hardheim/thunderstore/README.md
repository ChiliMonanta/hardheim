# HardHeim

**Odin's world, just brutal.** 

HardHeim is a complete difficulty overhaul built for Valheim using Jötunn. It grounds your survival experience, turning the tenth world into a much harsher, more unforgiving landscape where every victory must be earned.

## Features
- **Grounded Progression:** Designed for players who find the vanilla game too forgiving.
- **Server Enforcement:** Automatically synchronizes config files from the server to clients. Mod i mandatory for all clients.

## Installation
The easiest way to install HardHeim is using a mod manager like **r2modman** or the **Thunderstore Mod Manager**. 

### Manual Installation
1. Ensure you have **BepInEx** and **Jötunn** installed.
2. Download the `HardHeim.zip` archive.
3. Extract the contents and move `HardHeim.dll` into your `Valheim/BepInEx/plugins/` folder.

## Configuration
*(Optional: If your mod has a config file, explain it here)*  
You can tweak the difficulty settings inside the `HardHeim.cfg` file generated in your BepInEx config folder after launching the game once.
